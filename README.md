# 🎨 Pixel Painter

**Pixel Painter** is a simple and intuitive pixel art editor built with C++ and SDL2.  
Draw on a 50x50 grid, pixel by pixel, and save your artwork as a BMP file.  
Perfect for creating game sprites, pixel art drafts, or just enjoying retro-style creativity.

![Demo](demo.png) *(You can add a screenshot later)*

---

## ✨ Features

- 🖌️ **Mouse Drawing** – Hold left button and draw freely on the canvas
- 🎨 **16 Built-in Colors** – Includes basic colors and soft tones
- 🔲 **Toggleable Grid** – Press `G` to show/hide grid for alignment
- 💾 **Save as BMP** – Press `S` to save canvas as `pixel_art.bmp`
- 🧽 **Clear Canvas** – Press `C` to erase everything
- 🚪 **Exit** – Press `ESC` or close the window
